some-windows-scripts: 13 scripts .bat para resolver problemas do Windows

Uma coleção de scripts Batch autocontidos para problemas pontuais do Windows. A proposta é quase anti-produto: sem instalação, sem dependências, só baixar e executar.

Abrir projeto
$ system-doctor --quick

checking network... ok
checking audio... ok
checking updates... ok

all systems feel better.

Destaques

Como usar

  1. Baixe o arquivo .bat de que você precisa ou clone o repositório
  2. Veja na tabela se ele exige administrador
  3. Clique com o botão direito e escolha “Executar como administrador”, ou dê dois cliques se não exigir
  4. Aguarde o script terminar e pressione qualquer tecla para fechar
