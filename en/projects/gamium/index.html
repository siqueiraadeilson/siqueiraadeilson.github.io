Gamium: a decentralized, encrypted P2P chat app

A decentralized, encrypted P2P communication app. The project combines Electron, React, TypeScript, Vite, Gun.js, WebRTC, and Zustand to rethink chat, voice, and communities without a central server.

Highlights

  • Automatic updates for Windows, Linux, and macOS

Communication without a central server

Gamium uses Gun.js for peer-to-peer communication and WebRTC for voice and screen sharing. No central server stores conversations: identity is based on cryptographic keys, and messages are end-to-end encrypted.

Features

  • Direct messages with ECDH encryption
  • Public or private servers with multiple channels
  • Groups, a friends system, and online status
  • Voice channels and screen sharing
  • Frameless window, dark theme, and minimize to tray

Account recovery without a server

With no server, there is no “forgot my password”. The answer is a 12-word BIP39 recovery phrase, generated when the account is created, which restores access on another device.

Installation

  1. Download the installer for your platform from the GitHub releases page
  2. On Windows, run the installer; on Linux, use the AppImage or .deb package; on macOS, open the .dmg
  3. Create your account and store the recovery phrase somewhere safe
