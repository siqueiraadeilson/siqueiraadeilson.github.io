Ponteiro Studio: a web editor for custom mouse cursors

A web editor for custom pixel-art cursors. Draw on a 64 × 64 canvas or import PNG/GIF, customize colors and scale, set the click hotspot, test in a live 3D preview, and export as PNG, CUR, or ANI.

Highlights

  • Editor with pencil, eraser, clear, quick shapes, and shape redraw tools
  • Independent cursor, outline, and pencil colors, including custom values
  • Preset or canvas-picked click hotspot with a live preview

From drawing to a cursor on your computer

  1. Draw on a 64 × 64 grid or import a PNG or animated GIF
  2. Adjust the cursor, outline, and pencil colors
  3. Choose the click hotspot, preset or picked on the drawing
  4. Test it in the live preview
  5. Export as PNG, CUR, or ANI

Product decisions

Making a cursor usually takes an image editor plus a separate converter. Ponteiro Studio brings those steps into the browser and treats the click hotspot as part of creation, because it decides whether a cursor works well in real use.
