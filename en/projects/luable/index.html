Luable: a gamified platform to learn Roblox game programming

A learning platform for anyone who wants to program Roblox games. Luable organizes the journey into a gamified path with 16 modules and 132 short lessons, combining theory and practice in the browser — with a Luau IDE, instant feedback, and a certificate at the end.

Learning by doing, in the browser

Getting started with Roblox programming often means fighting setup and scattered tutorials. Luable replaces that with a path of short lessons and immediate practice: learners write real Luau in the browser IDE and get instant feedback.

How the path is organized

  1. Short lessons introduce one concept at a time
  2. Challenges are checked instantly, with friendly hints and explanations
  3. XP and progression keep the pace across all 16 modules
  4. Exams validate the content and unlock the PDF certificate
