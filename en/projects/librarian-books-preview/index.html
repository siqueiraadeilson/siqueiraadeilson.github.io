What the mod shows

Aim at a librarian villager and a discreet HUD displays up to three enchanted book trades, with names in your game language and the real emerald cost. Everything updates in real time, with no need to click the villager.

How to install

  1. Install Fabric Loader for your Minecraft version
  2. Install Fabric API
  3. Put the mod .jar file in your mods folder
  4. Launch the game with the Fabric profile

How to use it

Find a librarian villager and point your crosshair at them. Available books and prices appear on screen, with book and emerald icons.
